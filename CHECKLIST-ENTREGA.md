# Checklist final para a entrega — CP3 Mobile

## Configuração e execução

- [ ] Tenho o Node.js instalado.
- [ ] Executei `npm install` sem erros.
- [ ] Criei um projeto no Firebase Console.
- [ ] Adicionei um app Web nas configurações do Firebase.
- [ ] Ativei Authentication com E-mail/Senha.
- [ ] Criei o Cloud Firestore.
- [ ] Publiquei o conteúdo de `firestore.rules` no Firebase.
- [ ] Criei o `.env` preenchido com os dados corretos.
- [ ] Executei `npx expo start --clear` e abri no celular/emulador.

## Testes obrigatórios

- [ ] Cadastro válido e inválido.
- [ ] Login válido e senha incorreta.
- [ ] Recuperação de senha.
- [ ] Adição de tarefa, inclusive teste de título vazio.
- [ ] Listagem de tarefas no aplicativo e no Firestore.
- [ ] Concluir/reabrir tarefa.
- [ ] Filtros Todas, Pendentes e Concluídas.
- [ ] Exclusão: cancelar e confirmar.
- [ ] Logout e retorno ao login.
- [ ] Confirmação de que outra conta não acessa minhas tarefas.
- [ ] `npm test` passou.

- [ ] `README.md` responde ao item 1: definição do aplicativo.
- [ ] `README.md` responde ao item 3: conceitos usados no projeto.
- [ ] Código React Native completo e arquivos de regras no repositório GitHub.
- [ ] Repositório NÃO contém `.env`, senhas pessoais ou credenciais administrativas.
